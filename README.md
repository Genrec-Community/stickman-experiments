# stickman-experiments

Sandbox for trying the [stickman-video-director](https://github.com/kaomei/stickman-video-director) skill with OpenCode free models. Fully separate from the production `youtube-shorts-automation` pipeline: no schedules, no uploads, manual dispatch only, videos come out as run artifacts.

Run: Actions -> stickman-experiment -> Run workflow (pick topic/style/ratio).
